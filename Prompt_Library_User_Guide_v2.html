Prompt Library Workbook — User Guide

This guide helps teams store, find, and reuse prompts consistently across banking and analytics use cases. It explains the workbook structure, what each column means, and a simple workflow to run prompts reliably.

Status: ready to present Sheets: Prompt_Library, User Guide Last updated:

1. Purpose

Why this workbook exists

This workbook stores reusable prompts for banking and analytics use cases. Each row represents a single prompt with its persona, required inputs, and expected output — so teams can find and reuse prompts quickly and consistently.

Outcome you want: fewer one-off prompts, faster discovery, and predictable outputs across teams.

2. Sheets

Where to look for what
  • Prompt_Library: the main catalog of prompts (one row per prompt).
  • User Guide: how to interpret columns and maintain the catalog.

3. Column definitions (Prompt_Library)

What each field means and how to use it
Column ↕ Description ↕

Speed tip: keep Tags/Labels rich and consistent — it improves prompt discoverability immediately.

4. How to use a prompt

A repeatable workflow that avoids surprises
  1. Filter by Category, Sub-Category, Persona, or Tags/Labels to find a relevant row.
  2. Read the Prompt Objective to confirm it matches your task.
  3. Collect the items listed in Required Input before you run the prompt.
  4. Paste the Prompt into your LLM, then fill placeholders like {placeholders} or attach files as described.
  5. If you adapt a prompt, save it as a new Sr.No. and update Objective, Required Input, and Output Format.
  6. For better search results, use precise keywords and phrases in your query.

5. Example usage

Concrete “ask → pick → run” patterns
Usage 1 — Competitor analysis (banking products in US) copy available

Ask Copilot/LLM to surface the most relevant prompt from the library and then run it.

I want to run the competitor analysis for the banking products in US. Show me the most relevant prompt from the library.
  • Copilot suggests related prompts (banking products, offers, ranking).
  • Select the most useful one and ask Copilot to execute the prompt.
Usage 2 — Convert SAS code to Python copy available

Use the code translation prompt; replace placeholders with your SAS snippet and constraints.

I want to convert the SAS code to corresponding Python code. Show me the most relevant prompt from the library.
  • Copilot provides the relevant translation prompt.
  • Replace the SAS code placeholder in the prompt and execute.
Usage 3 — Draft a work summary copy available

Ask for a prompt that turns your notes into a first draft (structured and editable).

I want to create a draft of my work. Show me the related prompt from the library.
  • Copilot returns prompts aligned to your query.
  • Proceed with the best-fit prompt to generate results.

7. Finding best suitable prompts

Better queries → better matches

How do I search for prompts I’m interested in?

  • Write your query with appropriate keywords (domain, task, tool, expected output).
  • Add this line to guide selection toward the best match:
Provide me the relevant prompts and suggest the best prompt for **my use case**.

8. Maintenance tips

Keep the library clean and easy to trust
  • Keep wording consistent and avoid overlapping prompts unless clearly versioned.
  • When you change a prompt, update Last Update Date and add a short note in User Feedback.
  • Use clear, generic personas so others can quickly understand who the prompt is for.
  • Add new prompts at the bottom of the table and avoid reusing Sr. No. values.
